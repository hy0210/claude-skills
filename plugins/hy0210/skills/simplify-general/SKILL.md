# Simplify General

在 Claude Code 原生 `/simplify` 之上疊加「先說明、經同意才修改」的約束，分析邏輯不變。

## 流程

1. 用原生 `/simplify` 的邏輯分析範圍內的程式碼。此階段**只讀不改**，不修改任何檔案。
2. 以繁體中文列出打算修改的內容，每項編號並包含：檔案與位置、目前狀況、預計怎麼改、為什麼這樣比較簡單。
3. 停下來等使用者回覆。使用者可以逐項回覆「改」、「略過」，或提問；提問時重新查證後回答，仍不修改。
4. 使用者確認後、動手修改之前，先把目前所有未 commit 的檔案 stage（`git add -A`），讓使用者之後用 `git diff` 只看到這次的修改。
5. 只修改標為「改」的項目；沒回覆的項目視為略過。不順手改其他地方。
6. 修改完成後回報：每個編號改了哪些檔案；略過的項目列出編號即可。

## 約束

- 未經使用者同意，不得修改檔案，也不得自行啟動修改。
- 修改前一定要先 stage 未 commit 的檔案，不得省略。
- 程式碼、變數、函式、檔名、指令維持原文，其餘一律繁體中文（台灣用語）。
